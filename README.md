# FastAPI
1) Создать веб-сервис который генерирует случайный четырёхзначный код. Новый код по обновлению страницы. Требуется скинуть URL и показать код на питоне.
2) Создать веб-сервис, который генерирует случайный четырёхзначный код, но только после авторизации. После обновления страницы – выход.


| URL | Что делает |
|-----|------------|
| `/` | 4-значный код, каждый раз новый |
| `/auth/` | код после логина `admin`/`admin`; F5 сессия не сохраняется |


# Запуск
```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --reload
```
